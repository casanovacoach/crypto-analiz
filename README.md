Скрипт получает данные о топ-50 монетах по рыночной капитализации, определяет 3х лидеров роста и падения за 24 часа, находит монету с максимальным объёмом торгов, считает общую капитализацию и делает отчёт в формате json.

Результаты выводятся в терминале с помощью Rich и сохраняются в `crypto_report.json`.

## Что умеет (функции)

* получает топ-50 криптовалют из CoinGecko API;
* повторяет запрос при сетевой ошибке;
* находит топ-3 роста и падения за 24 часа;
* определяет максимальный объём торгов;
* считает суммарную капитализацию;
* выводит результаты в красивой таблице;
* сохраняет отчёт в JSON.

## Структура проекта

```text
crypto-analyzer/
├── main.py
├── api_request.py
├── analysis.py
├── design.py
├── report.py
└── crypto_report.json
```

* `main.py` — запуск программы и управление основным процессом.
* `api_request.py` — запросы к CoinGecko API и @retry.
* `analysis.py` — анализ полученных данных.
* `design.py` — вывод результатов через Rich.
* `report.py` — создание и сохранение JSON-отчёта.

После запуска программа загружает данные, показывает таблицу с лидерами роста и падения и создаёт файл:

```text
crypto_report.json
```

Необходимые библиотеки в pyproject.toml
